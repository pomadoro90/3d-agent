# 3D-Agent Examples

## first_scene.py — MVP
```bash
python examples/first_scene.py --prompt "cyberpunk robot with neon blue lights"
```

## iterative_optimization.py — Полный feedback loop
```bash
python examples/iterative_optimization.py --prompt "medieval castle on a hill" --max-iter 5
```

## batch_generation.py — Массовая генерация
```bash
python examples/batch_generation.py --prompts-file prompts.txt --output-dir ./batch_output
```
